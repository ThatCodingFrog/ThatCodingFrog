# AI-Assisted Code Policy (written with AI assistance)

This repository may include code that was written or refactored with the assistance of AI tools (e.g., ChatGPT, GitHub Copilot). To ensure transparency and maintain high quality, the following guidelines are applied to all AI-assisted changes:

## 🧾 Documentation
- All AI-assisted modifications are clearly noted in code comments or commit messages.  
- Comments include information on **which functions or sections** were influenced by AI and **what was changed**.  

## 🧪 Verification
- Every AI-generated or AI-refactored section of code is **reviewed, tested, and verified** to work as intended before being merged.  
- No AI-generated code is accepted without **manual inspection** and, where possible, **runtime validation**.

## 🎯 Responsibility
- The project maintainer(s) take full responsibility for all merged code, regardless of AI involvement.  
- AI tools are used only as assistants to increase productivity, not as authoritative sources.

## 🧩 Purpose
This policy ensures that AI can be safely and transparently integrated into development workflows without compromising:
- Code reliability  
- Original author attribution  
- Project integrity
